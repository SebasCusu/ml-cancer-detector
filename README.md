# Breast Cancer Classification

A Machine Learning project that uses **Logistic Regression** to classify breast cancer tumors using the Wisconsin Breast Cancer Dataset.

## Technologies
- Python
- Pandas
- Scikit-learn
- Logistic Regression
- StandardScaler

## Features
- Data loading and feature selection
- Train-test splitting
- Feature standardization
- Model training and prediction
- Performance evaluation using Accuracy and Classification Report

## Model Performance
- Accuracy: **97%** on the test set.

## Disclaimer
This project is for educational purposes only. It is not intended for medical diagnosis or clinical use.
